# mariko-tools-test
## world-rpg

世界の有名な場所を旅して魔物を倒す3DのRPG「テラルート」（`world-rpg/index.html`）。第一章はウユニ塩湖。

- はじめにキャラメイク（肌・髪型・前髪・髪の色・目の色・服・服の色・飾りの色・体つき・体格・背丈・名前）。手帳の「着替え」からやり直せる
- スマホ：画面の左側で移動、右側のドラッグで視点。攻撃・回転斬り・回避・ジャンプ・回復・飛ぶのボタン
- PC：WASDで移動、ドラッグで視点、J攻撃 / L回転斬り / K回避 / スペースでジャンプ / F飛ぶ / H回復 / E話す
- ゲームの中の一日は約10分。朝・昼・夕・夜で空と光が変わり、夜だけ出る魔物がいる
- 地面は鏡張りで、空・雲・星・キャラが映る
- 西の湖でフラミンゴの羽を拾うと空を飛べる（飛行中はジャンプで上昇、回避で下降）
- 魔物を倒すと経験値・お金・素材。塩のホテルの屋台で回復薬、武器の強化、旅装、ひと休み（朝まで／夜まで）
- 南の「結晶の環」にボス。倒すと「次の国への切符」
- おみやげは7つ。地図の黄色い点が未回収
- 手帳の「設定」で画質（きれい／ふつう／軽い）、音、時間送り、写真モード
- 進み具合は端末に自動で保存される。手帳の「ステータス」に「セーブする」ボタン、「設定」に文字で控えを取れる「セーブコード」
- 服はレベルで増える（Lv3 ロングコート、Lv5 軽鎧、Lv8 ローブ、Lv12 騎士の鎧、Lv16 星の礼装）。手帳の「着替え」から
- 依頼（7つ）、宝箱（10個）、地図からのワープ（右上の丸い地図をタップ）、相棒のアルパカ、じどう回復、写真モードのポーズ
## flying-game

夕焼けの海の上を飛ぶ3Dフライトゲーム（`flying-game/index.html`）。

- スマホ：画面のどこでもドラッグして操縦
- PC：矢印キー / WASD で操縦、Enter でスタート
- 光るリングをくぐると燃料が回復（キラキラ・スコア表示・燃料ゲージが光る演出つき）
- 金のリングは燃料満タン＋高得点
- ダブルタップ（PCはスペース）で一回転。回転中は岩をすり抜ける
- 青い玉を取るとシールド。岩に一回ぶつかっても守ってくれる
- 岩のすぐ横を通るとニアミスボーナス
- 時間とともに夕焼けから夜へ（18:00 → 19:30）。星と月が出る
- 浮いている岩にぶつかると終わり

## kaede-game

かえちゃん専用のリニアモーターカーゲーム「かえちゃんごう」（`kaede-game/index.html`）。5さい向けで、文字はひらがな・カタカナだけ。スマホの読み上げで声も出る。

- リニアは高架のガイドウェイの上を浮いて走る
- 画面をタッチでジャンプ、空中でもう一回タッチで「くるりん」（くるりん中は障害物に当たらない）
- 星を集める。さばの味噌煮・くるま・大太鼓は星5こ
- 障害物に当たっても「ガタン！」と少し遅くなるだけで、ゲームオーバーはない
- 駅（ほいくえん → たいそう → いしだ → ふじさん）に着くたびにスタンプカードにスタンプ
- 駅のあいだで、わるもの3体（もくもくおばけ・ゴロゴロかみなり・ガラクタキング）が通せんぼ
  - 「へんけい」で「かえちゃんロボ」になる。ドンボタンでロケットパンチ・スターショット・ビームを順番に撃つ
  - 当てるとひっさつゲージがたまり、満タンで「ひっさつビーム」
  - わるものの攻撃はロボのバリアが自動でガードする
- ゴールの「かえちゃんえき」で運転士認定証がもらえる。回数といちばん多く集めた星の数を覚えている
- PC：スペース / ↑ / Enter でジャンプ・攻撃、B でひっさつビーム

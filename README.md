# mariko-tools-test
## flying-game

夕焼けの海の上を飛ぶ3Dフライトゲーム（`flying-game/index.html`）。

- スマホ：画面のどこでもドラッグして操縦
- PC：矢印キー / WASD で操縦、Enter でスタート
- 光るリングをくぐると燃料が回復（キラキラ・スコア表示・燃料ゲージが光る演出つき）
- 金のリングは燃料満タン＋高得点
- ダブルタップ（PCはスペース）で一回転。回転中は岩をすり抜ける
- 青い玉を取るとシールド。岩に一回ぶつかっても守ってくれる
- 岩のすぐ横を通るとニアミスボーナス
- 時間とともに夕焼けから夜へ（18:00 → 19:30）。星と月が出る
- 浮いている岩にぶつかると終わり

## kaede-game

かえちゃん専用の新幹線ゲーム「かえちゃんごう」（`kaede-game/index.html`）。5さい向けで、文字はひらがな・カタカナだけ。スマホの読み上げで声も出る。

- 画面をタッチでジャンプ、空中でもう一回タッチで「くるりん」（くるりん中は障害物に当たらない）
- 星を集める。さばの味噌煮・ゴーヤチャンプルー・大太鼓は星5こ
- 障害物に当たっても「ガタン！」と少し遅くなるだけで、ゲームオーバーはない
- 駅（ほいくえん → たいそう → さばのみそに → ふじさん）に着くたびにスタンプカードにスタンプ
- 最後は「もくもくおばけ」が通せんぼ。へんけいボタンで「かえちゃんロボ」になって、太鼓をドンドン叩いてやっつける
- ゴールの「かえちゃんえき」で運転士認定証がもらえる。回数といちばん多く集めた星の数を覚えている
- PC：スペース / ↑ / Enter でジャンプ・太鼓
